Project Overview

Project Objectives

This project presents a comprehensive exploratory, statistical, and inferential analysis of the GDSC (Genomics of Drug Sensitivity in Cancer) dataset, integrating molecular, pharmacological, and clinical data from tumor cell lines.

Key Goals

  • Explore pharmacological variables (LN_IC50, AUC, Z-SCORE)
  • Analyze sensitivity differences across tumor types
  • Evaluate associations with molecular pathways and mutations
  • Build explanatory models (logistic and linear regression)
  • Prepare pipeline for predictive modeling phase

Dataset & Variables

Data Source

Official GDSC portal: www.cancerrxgene.org

Main Variables

Drug Response Metrics

  • LN_IC50: Log-transformed IC50
  • AUC: Area Under Curve
  • Z_SCORE: Standardized sensitivity
  • MIN_CONC / MAX_CONC: Concentration range
  • RMSE: Model fit quality

Clinical Metadata

  • TCGA_DESC: Tumor type description
  • Cancer.Type: Matching TCGA label
  • Cell line characteristics
  • Tissue origin

Molecular Features

  • TARGET_PATHWAY: Drug target pathway
  • Mutational Status: WES data
  • Gene expression profiles
  • Genomic alterations

Analysis Methodology

1. Data Loading & Initial Description

  • Dataset exploration with glimpse() and summary()
  • Global descriptive statistics
  • Metrics by tumor type (TCGA_DESC)

2. Data Visualization

  • Boxplots of LN_IC50, AUC, and Z_SCORE distributions
  • Histograms of LN_IC50 and AUC
  • Scatterplot: AUC vs LN_IC50
  • Proportion charts: Sensitive vs Resistant by tumor type and molecular pathway

3. Categorical Sensitivity Variable Creation

Classification based on percentiles:

  • Sensitive: ≤ p25
  • Intermediate: p25 – p75
  • Resistant: ≥ p75

4. Correlation Analysis

  • Correlation matrix (LN_IC50, AUC, RMSE, MIN/MAX_CONC)
  • Visualization with GGally::ggcorr()

5. Inferential Statistical Analysis

Statistical Tests Applied:

  • Shapiro-Wilk: Normality testing
  • Kruskal-Wallis: Group comparisons (non-parametric)
  • ANOVA: Analysis of variance (parametric)
  • Dunn post-hoc test: Pairwise comparisons
  • Wilcoxon Mann-Whitney: Two-group comparisons
  • permANOVA: Multivariate analysis

6. Association with Mutations & Molecular Pathways

  • Frequency tables
  • Chi-square test
  • Fisher's exact test
  • Sensitive/Resistant proportion analysis
  • Pathway-specific Kruskal-Wallis tests

7. Explanatory Models

Logistic Regression

  • Odds Ratios calculation
  • Confidence intervals
  • OR visualization (forest plot)

Linear Regression

  • Coefficient estimation
  • Confidence intervals
  • Effect interpretation (positive/negative)
  • Visual representation of model effects
